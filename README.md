# Мовчазне королівство

Грати: https://andrii-vityk.github.io/movchazne-korolivstvo/

Покрокова браузерна гра для тренування читання українською. Мовчун вкрав слова, а герой читає їх і повертає у світ: досліджує данж на мапі, збирає руни й записки та перемагає боса.

```bash
node build.js
```

```bash
python3 -m http.server 8123 --directory dist
```

Далі відкрийте `http://localhost:8123`. Тексти лежать у `levels/*.md`, правила описані в `AGENTS.md`.
